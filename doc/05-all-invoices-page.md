# 4. All Invoices Page

## List screen
**Columns:** Invoice No., Client, Project, Company, Department, Invoice Date, Due Date, Amount, Currency, Status (Draft/Pending Approval/Sent/Partially Paid/Paid/Overdue/Cancelled), Tags, Actions (View / Edit* / Export PDF / Record Payment / Delete*)

*Edit and Delete follow the same rules as §3.5 — only Draft invoices are fully editable/deletable; Sent+ invoices can only be Cancelled.

**Filters:** Date range (invoice date or due date — toggle), Company, Department, Client, Status, Invoice Type, Tag
**Bulk actions:** Export selected (PDF/Excel), Send payment reminder for overdue selection
**Aging view (toggle):** groups overdue invoices into 0–30 / 31–60 / 61–90 / 90+ days buckets, per client
